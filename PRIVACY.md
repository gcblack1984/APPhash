# Informativa sulla privacy – APPhash

*Ultimo aggiornamento: novembre 2026*

APPhash è un programma per Windows che calcola le impronte hash di file, cartelle e archivi
compressi. Funziona interamente sul computer dell'utente.

- **Nessun dato raccolto.** APPhash non raccoglie, non memorizza e non trasmette informazioni
  personali né dati sull'utilizzo.
- **Nessuna connessione.** Il programma non si collega a Internet né ad altri sistemi in rete:
  non contiene telemetria, pubblicità, controllo degli aggiornamenti o servizi di terze parti.
- **I file restano sul computer.** I file analizzati vengono aperti in sola lettura e non
  vengono mai inviati altrove. I report vengono salvati solo dove sceglie l'utente.
- **Dati facoltativi nei report.** I campi "Operatore" e "Riferimento / note" vengono scritti
  soltanto nel report salvato dall'utente e non vengono conservati dal programma.

Se APPhash è installato dal Microsoft Store, l'installazione e gli aggiornamenti sono gestiti
da Microsoft secondo la propria informativa sulla privacy.

Per domande: [apri una segnalazione](https://github.com/gcblack1984/APPhash/issues).

---

## Privacy policy (English)

APPhash is a Windows program that computes file hashes. It runs entirely on the user's
computer. It does not collect, store or transmit any personal information or usage data, and
it does not connect to the Internet or to any other networked system: there is no telemetry,
advertising, update check or third-party service. Analysed files are opened read-only and
never leave the computer; reports are saved only where the user chooses. The optional
"Operator" and "Reference / notes" fields are written only into the report saved by the user.

When APPhash is installed from the Microsoft Store, installation and updates are handled by
Microsoft under its own privacy statement.

Contact: [open an issue](https://github.com/gcblack1984/APPhash/issues).
